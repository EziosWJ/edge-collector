# 第一阶段 Ticket 拆分

> 总 Spec：Issue #1
>
> ADR：ADR-0011
>
> 技术方案：`docs/design/phase-1-acquisition-technical-design.md`

第一阶段按纵向能力拆分，避免按“数据库 / 后端 / 前端”横向切割成无法独立验收的碎片。

建议实施顺序：

1. 采集配置基础：RS485 通道与设备配置持久化、CRUD、页面配置；
2. 馈电保护器协议契约与解析：把现有协议资料固化为可测试的解析规则；
3. RS485 Modbus RTU 单设备采集闭环：真实/模拟串口读取、周期采集、内存当前状态；
4. 同总线多设备与通信状态：串行调度、失败隔离、离线与恢复；
5. 当前状态 API 与 React 实时页面：HTTP 轮询展示当前值、时间和状态；
6. 第一阶段端到端验收与稳定性收口：完整闭环、回归、文档和开发机验收。

各 Ticket 不得引入 MQTT、告警、控制、Modbus Server、TCP/UDP、高开保护器或实时历史数据库。
