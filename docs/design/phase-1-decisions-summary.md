# 第一阶段实现决策摘要

第一阶段实现以 Issue #1、ADR-0011 和 `phase-1-acquisition-technical-design.md` 为准。

已确认：

- 首个设备：馈电保护器；
- 通信：RS485 + Modbus RTU；
- 开发环境：先在开发机完成；
- 配置：页面维护并持久化到 SQLite；
- 协议：寄存器与解析规则代码内置；
- 实时数据：只保存进程内当前状态，不逐轮入库；
- 运行拓扑：按物理 RS485 通道串行执行，不同通道独立；
- 通信状态：默认连续 3 次失败判离线，成功后恢复；
- 页面：设备列表 + 当前数据详情，HTTP 定时轮询；
- 第一阶段非目标：MQTT、告警、控制、高开保护器、TCP/UDP、Modbus Server、历史时序存储、SSE/WebSocket。
