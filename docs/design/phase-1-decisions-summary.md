# 第一阶段实现决策摘要

第一阶段实现以 Issue #1、ADR-0011、ADR-0013、ADR-0014 和 `phase-1-acquisition-technical-design.md` 为准。

已确认：

- 首个设备：馈电保护器；
- 通信：RS485 + Modbus RTU；
- 开发环境：先在开发机完成；
- 配置：页面维护通信通道、设备和多个有序寄存器读取块，持久化到数据库并热刷新采集运行时；
- 读取：读取块只支持 FC03 / FC04、零基地址和 `1～125` 个寄存器，同设备同功能码的范围不得重叠；
- 数据边界：当前阶段只保存 16-bit 无符号原始寄存器，不进行协议解析，也不逐轮入库；
- 运行拓扑：按物理 RS485 通道串行执行，不同通道独立；
- 通信状态：全部读取块成功为在线，部分成功为降级，全部读取块连续失败达到阈值才离线；
- API：保留 `/api/v1/acquisition/states`，以 `registerBlocks` 返回当前快照；
- 页面：“实时寄存器”采用设备列表 + 读取块详情，值默认 HEX，可全局切换 DEC / BIN；
- 第一阶段非目标：设备协议解析、完整 RTU 报文展示、MQTT、告警、控制、高开保护器、TCP/UDP、Modbus Server、历史时序存储、SSE/WebSocket。
