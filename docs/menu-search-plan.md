# 顶部菜单搜索

状态：已实现并验证。用户确认菜单范围、居中面板、拼音检索、默认列表，并授权后续细节由 Agent 决定。

## 功能边界

- 菜单搜索只查找当前侧栏导航中的可跳转叶子项，包含 Dashboard、示例页、用户菜单与外链。
- 复用现有导航转换、可见性过滤、排序和去重规则，不使用完整路由表作为索引。
- 目录只作为结果层级，不作为跳转目标。头像菜单的个人中心、修改密码不纳入搜索。
- 不检索业务数据，不维护最近访问记录。当前路由守卫只校验登录；菜单检索不新增或替代权限校验。

## 展示与交互

- 点击桌面顶部搜索入口或移动端搜索图标，或按 Ctrl/Cmd + K，打开居中面板并聚焦输入框。
- 未输入时按导航顺序显示全部可跳转项；结果显示图标、名称和父级层级，外链注明新标签页打开。
- 匹配页面名称与父级名称，支持中文、英文、拼音、首字母；忽略大小写与多余空白。
- 排序优先级：页面名称精确匹配、页面名称前缀、页面名称包含、页面拼音/首字母、父级匹配；同优先级保持导航顺序。
- 输入变化后默认选中首项，↑↓循环选择，Enter 跳转；中文输入法组合输入期间不处理选择和跳转键。
- 鼠标可直接点击结果；站内沿用 React Router，当前页不重复增加历史记录；外链新标签页打开。
- Esc、点击遮罩、关闭按钮关闭面板；关闭清空搜索，焦点返回打开前的位置。焦点限制在面板内。
- 其他模态弹窗打开时，不通过快捷键叠加菜单搜索。
- 菜单加载中给出提示；无结果时说明可按名称、拼音或首字母重试。菜单加载失败沿用现有默认导航兜底及侧栏提示，不新增接口调用。

## 实现与验证

- 搜索组件按需加载，使用 pinyin-pro 生成动态菜单名称的拼音索引，菜单变化时重建，输入采用 useDeferredValue。
- 术语记录在根 CONTEXT.md。本次为局部可逆 UI 功能，不另建 ADR。
- 执行 task frontend:lint、task frontend:build。
- 浏览器验证：入口及快捷键、中文/拼音/首字母/父级检索、排序、菜单过滤与去重、键盘和鼠标跳转、外链、输入法、无结果、关闭与焦点恢复、窄屏布局。

- `task frontend:lint`、`task frontend:build`、`git diff --check` 通过。构建仍提示主应用包超过 500 kB；搜索面板及拼音库已拆为独立按需加载文件。
- 本地 Chromium 使用模拟菜单接口，在真实 AppShell 与路由中验证上述交互；额外验证了当前页跳转不增加历史记录、外链 opener 隔离、Tab 焦点循环、其他模态弹窗不被快捷键打断、动态菜单移除与恢复，以及搜索不增加菜单接口请求。

- 拼音 API 依据 [pinyin-pro 官方说明](https://github.com/zh-lx/pinyin-pro) 与已安装版本的类型定义实现。
